# 🌱 KrishiSaathi — AI + IoT Smart Agriculture Assistant

**Team:** GreenCoder  
**Theme:** Agriculture, FoodTech & Rural Development  
**Category:** Software

## 📌 Overview
**KrishiSaathi** is an AI and IoT-based smart agriculture platform designed to help farmers make better decisions using real-time farm data. It collects information from IoT sensors, combines it with weather data, and uses AI/ML with agricultural rules to generate simple and actionable recommendations.

## 🎯 Problem
Farmers often depend on manual observation and experience to decide when irrigation is needed. However, actual soil and crop conditions can vary significantly. KrishiSaathi aims to provide data-driven insights for more informed farming decisions.

## 💡 Proposed Solution
The system:
- Collects real-time soil and environmental data using IoT sensors.
- Stores current and historical farm data.
- Uses AI/ML to analyze farm conditions.
- Predicts irrigation requirements and estimates water needs.
- Identifies possible crop-stress conditions.
- Provides recommendations and alerts through a farmer dashboard.

## ⚙️ Technology Stack
**IoT:** Soil-moisture sensor, temperature/humidity sensor, weather/rainfall input, microcontroller and wireless communication.  
**Backend:** Python, REST API, FastAPI.  
**AI/ML:** Python, Pandas, Scikit-learn, classification and regression.  
**Frontend:** Web/mobile dashboard with charts, alerts and recommendations.  
**Database:** Structured storage for sensor readings, farms, devices, predictions and alerts.

## 🔄 How It Works
**Sensors → Data Collection → Data Cleaning → Feature Engineering → ML Model → Prediction → Decision Engine → Recommendation**

The platform combines AI predictions with agricultural rules to provide safer and more practical recommendations.

## 🌾 Impact & Future Scope
KrishiSaathi can be expanded with crop recommendation, disease-risk prediction, yield prediction, weather-aware irrigation, crop-health monitoring, pH and water-level monitoring, automatic irrigation, mobile access, local-language support, multi-farm management, weather API integration, notifications and farm reports.

## 🚀 Vision
To make agricultural decision-making **smarter, more data-driven and accessible to farmers** by connecting real-world farm conditions with AI-powered insights.
